# 🟢 Nokia Bouncing Ball Game

A retro-style **Nokia Bouncing Ball game** recreated for modern platforms.  
Built as a fun project to bring back nostalgia, this version is **lightweight, fast, and addictive** — just like the original!

✨ **More features, levels, and mechanics are coming soon!** Stay tuned. 🚀

---

## 🎮 Features (Current Version)
- Classic bouncing ball mechanics
- Smooth controls
- Minimalist retro Nokia-style design
- Lightweight and easy to run

---

## 🚧 Upcoming Features
I’m currently scaling the project and adding:

- 🔄 Power-ups & obstacles
- 📱 Mobile-friendly touch controls
- 🌍 Leaderboards (online high scores)
- 🎨 Custom themes & ball skins
